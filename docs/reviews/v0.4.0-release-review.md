# Release review: v0.4.0 (23 tools with on-demand engines and native document conversion)

**Reviewer:** GPT-6.2 Astra, high effort, read-only, from `a9a1259`.

## Round 1 (`fc176e8`)

Four blockers, ten should-fixes, and two nits. All sixteen were resolved in the follow-up commit.

| # | Severity | Finding | Outcome |
| --- | --- | --- | --- |
| 1 | Blocker | `OfflineHTMLPDFRenderer` used `\|` in a WebKit content-rule URL filter, which WebKit rejects. | Fixed: replaced with separate per-scheme rules, required rule installation before loading, and added `OfflineHTMLPDFRendererTests`. |
| 2 | Blocker | `OfficeDocumentConverter` omitted `-noload` when passing HTML to `textutil`. | Fixed: added `-noload` to `textutilArguments`. |
| 3 | Blocker | `ArchiveTool` allowed `7zz` wildcard expansion on user-selected filenames. | Fixed: added `-spd` to both compress and extract arguments. |
| 4 | Blocker | Pinned `7zz` includes upstream's unRAR license restriction alongside LGPL/BSD code. | Owner decision: keep official `7zz` 26.06 on demand and disclose the full license (`LGPL-2.1-or-later, BSD-2-Clause, BSD-3-Clause, unRAR restriction`) in `EngineManifest`, `README.md`, and `AGENTS.md`. |
| 5 | Should-fix | `VideoDownloader` inherited user `yt-dlp` config and ambient plugin directories. | Fixed: added `--ignore-config` and `--no-plugin-dirs`. |
| 6 | Should-fix | `ArchiveTool` passed archive passwords on the `7zz` command line. | Fixed: passwords are delivered via piped stdin with bare `-p` on compress and no password argument on extract; newline passwords are rejected. |
| 7 | Should-fix | `Replace Audio` truncated video when looping was off and audio was shorter than video. | Fixed: added `-af apad` before `-shortest` when looping is off. |
| 8 | Should-fix | Fast Merge broke on filenames containing newlines. | Fixed: stages relative symlinks (`clip-0.<ext>`, …) and runs `ffmpeg -f concat -safe 1` in the staging directory. |
| 9 | Should-fix | `MediaInfoView` and `TrimVideoView` could apply stale `ffprobe` results after selection changes. | Fixed: tracks and cancels `probeTask` on selection change/disappear and checks selection identity before mutating state. |
| 10 | Should-fix | `EngineProcess` cancellation only signaled the immediate child PID. | Fixed: spawns each subprocess in an owned process group (`POSIX_SPAWN_SETPGROUP`) and signals `-pid` (`SIGTERM`, then `SIGKILL`). |
| 11 | Should-fix | `EngineTarXZ` PAX length addition and `EnginePKG` CPIO octal mode conversion could trap on malformed inputs. | Fixed: bounds-checked against remaining length and switched CPIO octal parsing to unsigned `UInt64` with exact conversions; added malformed-input tests. |
| 12 | Should-fix | `FileDropList` discarded folders and extensionless files when `allowedTypes` contained `.item`. | Fixed: accepts local items directly for `.item`, checks `contentTypeKey` before extension fallback, and passes `[.item, .folder]` in `ArchiveToolView`. |
| 13 | Should-fix | `ArchiveToolView` batch extraction lost earlier successes when a later archive failed. | Fixed: appends each extracted result to `savedURLs` as it completes. |
| 14 | Should-fix | `yt-dlp` standalone macOS binary was labeled `Unlicense` instead of `GPL-3.0-or-later`. | Fixed in `EngineManifest` and `README.md`. |
| 15 | Nit | `README.md` overstated `Convert Documents` conversion directions. | Fixed in `README.md` and `ToolCatalog`. |
| 16 | Nit | `DocumentTargetFormat.displayName` bypassed localization. | Fixed with `coreLocalized`. |

## Round 2 (`dfd5805`)

Confirmed Round 1 items #1–3, #5–8, and #12–15; raised two high-priority, three low-priority, and one nit finding, all fixed in the next commit:

- Protected `EngineProcess` stdin pipe writes with `fcntl(fd, F_SETNOSIGPIPE, 1)` and added `engineProcessIgnoresBrokenStdinPipe`.
- Kept `EngineProcess` `ProcessGroupBox` active until both `waitpid` and stdout/stderr EOF complete so delayed `SIGKILL` still fires when a descendant ignores `SIGTERM`; updated the cancellation test to trap `SIGTERM` in a child holding stdout open.
- Switched `MediaInfoView` and `TrimVideoView` probes to a monotonic `probeGeneration` token so A → B → A cancellation cannot clear `isLoading` for a newer probe.
- Expanded `AGENTS.md` to list the full `7zz` license (`LGPL-2.1-or-later, BSD-2-Clause, BSD-3-Clause`, and upstream's unRAR license restriction).
- Prepended a valid 11-byte PAX record in `tarXzRejectsMalformedPAXLengthWithoutTrapping` so the oversized length is parsed at a nonzero cursor.
- Localized the `.pdf` and `.html` cases of `DocumentTargetFormat.displayName`.
